# Portfolio Website Requirements (Frontend Only)

## 1. Project Objective

Build a modern, high-performance developer portfolio that:

* Attracts freelance clients (international)
* Helps secure remote job opportunities
* Demonstrates advanced frontend + UI skills
* Showcases 3D + animation capabilities

---

## 2. Target Audience

Primary:

* Startup founders
* Freelance clients (USA, UK, EU)
* Agency owners

Secondary:

* Recruiters
* Tech hiring managers

---

## 3. Website Structure

Required Sections:

1. Hero (3D Tech Sphere)
2. About
3. Skills
4. Projects (Bento Grid)
5. Services
6. Experience
7. Contact

---

## 4. Hero Section Requirements

Must include:

* Full screen layout
* Name + tagline
* CTA buttons
* 3D interactive Tech Sphere

3D Scene:

* Floating tech icons (React, Next.js, TS, Node, etc.)
* Orbit animation
* Mouse interaction
* Emerald glow effect

---

## 5. About Section

Purpose:

Quick professional introduction

Rules:

* Max 30 seconds reading time
* No long paragraphs
* Focus on value proposition

---

## 6. Skills Section

Display:

* Categorized skill badges

Categories:

* Frontend
* Backend (conceptual only)
* Mobile
* Tools

Style:

* Clean grid layout
* Hover highlight effects

---

## 7. Projects Section (Most Important)

Layout:

Bento Grid

Requirements:

* 1 featured project (large card)
* Remaining projects in smaller cards
* Hover animations required

Each project must include:

* Title
* Description
* Tech stack
* Screenshot
* GitHub link
* Live link

---

## 8. Services Section

Purpose:

Convert visitors into clients

Must include:

* Web Development
* Mobile App Development
* Dashboard Development
* UI Implementation
* API Integration (frontend consumption)

Each service card must show:

* Title
* Description
* Outcome delivered

---

## 9. Experience Section

Format:

Timeline

Includes:

* Role
* Company (or freelance label)
* Duration
* Key achievements

---

## 10. Contact Section

Must include:

### Contact Form

* Name
* Email
* Message

### Direct Links

* Email
* GitHub
* LinkedIn
* WhatsApp

### CTA

* “Book a Free Call”

---

## 11. Animation Requirements

Level:

Medium Cinematic

Allowed:

* Fade in on scroll
* Slide up transitions
* Stagger animations
* Hover lift effects
* Magnetic buttons
* Page transitions

Not allowed:

* Scroll hijacking
* Excessive motion
* Distracting animations

---

## 12. 3D Requirements

Hero only usage.

Must:

* Load lazily
* Be responsive
* Degrade on mobile
* Not block main thread

---

## 13. Design System

Style:

Dark + Emerald Glassmorphism + Minimal UI

Principles:

* Clean spacing
* Strong typography hierarchy
* Subtle glow accents
* No visual clutter

---

## 14. Performance Requirements

Targets:

* Lighthouse Score: 95+
* LCP: < 2.5s
* CLS: < 0.1

Optimization rules:

* Image optimization required
* Code splitting enabled
* Lazy load heavy components

---

## 15. SEO Requirements

Must include:

* Meta tags
* Open Graph
* Twitter cards
* Sitemap
* Robots.txt

Keywords:

* Frontend Developer
* React Native Developer
* Next.js Developer
* Software Engineer

---

## 16. Responsiveness

Must support:

* Mobile
* Tablet
* Laptop
* Desktop

3D scene must degrade gracefully on mobile.

---

## 17. Success Criteria

Portfolio is successful if:

* Loads fast (<2s)
* Clearly communicates skills
* Generates freelance inquiries
* Works perfectly on all devices
* Feels premium and modern
